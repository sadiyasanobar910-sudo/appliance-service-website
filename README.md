# appliance-service-website

## Overview
Service Department 24/7 is a full-service appliance repair platform designed to help users book repair services for home appliances.

## Features
- Appliance service booking
- Responsive website design
- Customer support integration
- Hosting and DNS configuration
- Service-specific pages

## Technologies Used
- HTML
- CSS
- JavaScript
- Hosting & DNS
- Database Integration
